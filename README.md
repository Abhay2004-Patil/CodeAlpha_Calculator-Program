# 🧮 Calculator Program in C

## 📖 Overview
This project is a simple calculator developed in C that performs basic arithmetic operations using user-defined functions.

## ✨ Features
- Addition
- Subtraction
- Multiplication
- Division
- Modular Design using Functions
- User-Friendly Menu

## 🛠️ Technologies Used
- C Programming
- Functions
- Switch Case
- User Input/Output

## 🚀 How to Run
1. Compile the program:
   gcc calculator.c -o calculator

2. Run the executable:
   ./calculator
